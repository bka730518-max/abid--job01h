# Sylhet Polytechnic Institute — Student Card

এই রেপোজিটরিটিতে একটি সরল স্টুডেন্ট ইনফো (HTML) পেজ আছে, GitHub-এ আপলোড করে আপনি GitHub Pages দিয়ে লাইভ করতে পারবেন।

## কন্টেন্ট
- `index.html` — মূল স্টুডেন্ট তথ্য পেজ (HTML + inline CSS)

## GitHub-এ আপলোড করার ধাপ (সংক্ষেপে)
1. নতুন রিপোজিটরি তৈরীর করুন (e.g., `sylhet-student-page`).
2. এই ফাইলগুলো রিপোজিটরিতে যোগ করুন (upload বা `git` ব্যবহার করে).
3. (প্রয়োজনে) `main` বা `gh-pages` ব্রাঞ্চ থেকে GitHub Pages সক্রিয় করুন — Repository > Settings > Pages।
4. `index.html` স্বয়ংক্রিয়ভাবে পেজ হিসেবে প্রদর্শিত হবে।

---

This repository contains a simple static HTML student info page.

To upload:
- Create a new GitHub repository.
- Upload `index.html` and `README.md` via the web UI or push using `git`.
- Enable GitHub Pages in the repository settings to host the page.
